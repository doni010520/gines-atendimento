6. Validação de Catálogo *
Para catálogos com variações (cor, voltagem, tamanho, etc.)
Utilize linhas separadas para cada variação e encontre 3 catálogos para CADA variação. Confirme com OK que todos os catálogos desta linha são da mesma variação.
Verifique se o catálogo pertence a uma marca registrada no Mercado Livre.
Produtos com marca registrada no ML são de uso exclusivo do titular — vender nesses catálogos pode gerar remoção de anúncio ou bloqueio de conta.

Como validar:
1. Identifique o nome da marca nos catálogos pesquisados.
2. Acesse busca.inpi.gov.br e pesquise a marca no banco de marcas do INPI.
3. Se a marca estiver registrada e ativa, não venda nesse catálogo.
4. Só confirme OK se a marca não tiver registro ativo no INPI ou se for uma marca genérica/sem proteção.
